# CampusConnect user guide

## Browse CampusConnect

Open the CampusConnect website in a mobile or desktop browser. Use the bottom
navigation to open:

- **Feed** - recent campus activity
- **Community** - discussions and comments
- **Market** - student marketplace listings
- **Lost & Found** - lost or found item reports
- **News** - official announcements
- **Institutions** - Kenyan institution directory
- **Events** - campus events
- **Jobs & Internships** - student opportunities

## Create an account

Select **Sign In / Register** at the top of the app.

Registration requires:

- Name
- Valid email address
- Password of at least eight characters

An account is optional for browsing and using some public posting features, but
it provides account profile and session management.

## Create a community post

1. Open **Community**.
2. Select **Post**.
3. Enter your name and, optionally, a contact number.
4. Select a topic.
5. Enter a title and message.
6. Optionally attach an image or document.
7. Submit the post.

Posts may receive comments. Keep names accurate and avoid publishing sensitive
personal information.

## Use the marketplace

Open **Market**, then **List Item**. Add:

- Your name
- Contact or phone number
- Title
- Description
- Optional price
- Category
- Optional photo

Meet in a safe public location for transactions. CampusConnect does not process
payments or guarantee listings.

## Report lost or found items

Open **Lost & Found**, choose **Report**, then provide:

- Your name
- Contact number
- Lost or found status
- Item title
- Description
- Location

Do not include private identity details such as passwords or full ID numbers.

## Find an institution

Open **Institutions**. Search by institution name, abbreviation, county, or
category. Select an institution to view its community. Use **Join** where
available to register your local interest in the community.

## Find events and opportunities

Open **Events** to browse upcoming campus events or publish an event with its
time and venue. Open **Jobs & Internships** to browse opportunities and
application details. Keep private the edit token returned after creating
content; supported owner-only API changes require that token.

## Report inappropriate content

Select the report action on supported content, select a reason, and submit it.
Reports are sent to the administrator moderation queue.

## Install the PWA

On supported mobile browsers:

1. Open CampusConnect.
2. Open the browser menu.
3. Select **Install App** or **Add to Home screen**.

## Safety

- Never share passwords or financial PINs.
- Verify sellers and buyers before meeting.
- Avoid advance payments to unknown people.
- Use a public, well-lit meeting place.
- Report threats, fraud, or suspicious listings.
