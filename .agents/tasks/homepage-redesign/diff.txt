+## Executive Summary
+
+CampusConnect is a working, multi-feature Flask SPA. The backend is well-structured with 13 Python source files, a 24-table SQLite/PostgreSQL database, Supabase-compatible storage, and 10 API blueprints. The frontend is a single-page app (SPA) driven by vanilla JavaScript loaded into `templates/index.html`. The platform already has a solid foundation ΓÇö community posts, marketplace, lost & found, announcements, institution directory with per-institution communities, events, jobs/internships, reactions, notifications, and a full advertiser portal.
+
+**What's already working:**
+- Student feed aggregating posts, marketplace, lost & found, announcements
+- Community posts with comments, file/image attachments, topic filtering
+- Marketplace with categories, images, owner-token edit/delete
+- Lost & found
+- Announcements (admin-only posting, correctly enforced)
+- Institutions directory (600+ Kenyan institutions seeded) with per-institution community posts and comments
+- Events (create, edit, delete with owner token; poster image upload)
+- Jobs & internships (`Opportunity` model, `campus.py` routes)
+- Reactions (like/celebrate/support) on posts, institution posts, events, opportunities
+- Notifications model and API (read, mark-read)
+- Account system (register, login, logout, profile update with bio and institution link)
+- Advertiser portal (register ΓåÆ admin approval ΓåÆ campaigns ΓåÆ placements ΓåÆ impressions/clicks/stats)
+- Admin panel (ads, announcements, posts, marketplace, lost & found, reports, institutions, advertiser management, campaign approval, revenue, payments)
+- Content reporting system
+- Rate limiting, idempotency protection, file signature validation, owner-token-based content editing
+- PWA manifest and service worker
+
+**What's missing or incomplete:**
+- No homepage dashboard (currently just navigates to Feed on load)
+- Groups section: nav button exists, no render function and no backend
+- Accommodation section: nav button exists, no render function and no backend
+- Scholarships: not in `Opportunity.opportunity_type` (only `job` and `internship` allowed)
+- Private messaging: model, routes, and UI absent
+- User profile page: Account model exists but no profile view beyond the account bar
+- Password reset / email verification: not implemented
+- Google sign-in: not implemented
+- Global search: search bar in header exists, not wired to any handler
+- Roommate finder: no model, routes, or UI
+- Nearby services: no model, routes, or UI
+- Learning hub / file sharing: file upload works in community posts but no dedicated section
+- Business profiles: Advertiser model exists but no public-facing profile pages
+- Trending posts algorithm: feed is chronological, no score/weight
+- Dynamic homepage dashboard with real data sections: not implemented
+- `account.js` has `showMyPosts()` returning "coming soon"
+- Two nav items ("Groups", "Rooms") navigate to undefined `renderGroups()`/`renderAccommodation()` ΓÇö these will silently fail or throw a JS error
+
+**Three deleted/stale modules** have `.pyc` files but no source: `announcements.py`, `auth.py`, `community.py`, `marketplace.py`, `library.py`, `timetable.py`, `assignments.py`, `dashboard.py`, `lostandfound.py`. Their logic has been consolidated into `public.py` and `campus.py`. This is not a problem but confirms previous refactors.

+## 14. What is Out of Scope for a Single Implementation Pass
+
+The following are complex enough to warrant separate dedicated passes:
+
+- **Private messaging** ΓÇö requires a full message/conversation data model, real-time delivery (WebSocket or polling), UI threads, and read receipts. This is a major feature.
+- **Email verification and password reset** ΓÇö requires adding an email library (`Flask-Mail` or SendGrid), new DB tables for verification/reset tokens, and email templates. The hosting environment (Render) must be configured with SMTP credentials.
+- **Google sign-in** ΓÇö requires `authlib`, OAuth2 flow, handling existing accounts with matching email, and secure token storage.
+- **Nearby services** ΓÇö requires either a curated data model (significant data entry work) or integration with Google Places API (API key, billing, frontend Maps SDK).
+- **M-Pesa integration** ΓÇö requires Safaricom Daraja API credentials, callback endpoint, payment reconciliation logic, and testing in a sandbox.
+- **Real-time notifications** ΓÇö requires WebSocket support (`flask-socketio`) and a frontend connection manager.
+- **Full-text global search** ΓÇö requires either PostgreSQL `tsvector` indices (Alembic migration) or a dedicated search service.
+- **Trending algorithm** ΓÇö requires a scoring table and background job or query that weights recency + engagement. No background task runner exists.

+# CampusConnect
+
+CampusConnect is a Kenyan student community platform for community discussions,
+institution communities, marketplace listings, lost-and-found reports,
+announcements, and advertising campaigns. It is implemented as a Flask PWA and
+can be installed or used in a mobile or desktop browser.
+
+## Features
+
+- Community feed and topic-based posts
+- Image and document attachments
+- Post comments and reporting
+- Student marketplace listings
+- Lost-and-found reports
+- Campus events and job/internship opportunities
+- Institution directory and institution communities
+- Optional student accounts
+- Administrator moderation dashboard
+- Advertiser registration and campaign management
+- Impression, click, placement, and revenue tracking
+- Supabase PostgreSQL and Storage configuration for hosted deployments
+- Owner edit tokens and idempotent public create requests
+- PWA browser installation support
+

+| API documentation | Developers and integrators |

+

+
+- Python 3

+## Quick start
+
+```powershell
+cd C:\Users\user\Documents\NetBeansProjects\CampusConnect
+python -m pip install -r requirements.txt
+Copy-Item .env.example .env
+python -m flask --app run db upgrade
+python seed.py
+python run.py
+```
+

+`http://127.0.0.1:5000/health`.

+migration, RLS, backup, domain, and outstanding production limitations.

+def issue_owner_token(resource_type=None, idempotency_key=None):
+    if resource_type and idempotency_key:
+        token = hmac.new(
+            current_app.config['SECRET_KEY'].encode('utf-8'),
+            f'{resource_type}:{idempotency_key}'.encode('utf-8'),
+            hashlib.sha256,
+        ).hexdigest()
+    else:
+        token = secrets.token_urlsafe(32)
+    token_hash = hashlib.sha256(token.encode('utf-8')).hexdigest()
+    return token, token_hash
+
+
+def idempotency_key_hash(resource_type, raw_key):
+    if raw_key is None:
+        return None
+    if len(raw_key) < 16 or len(raw_key) > 200:
+        raise ValueError('Idempotency-Key must be between 16 and 200 characters.')
+    return hashlib.sha256(f'{resource_type}:{raw_key}'.encode('utf-8')).hexdigest()
+
+
+def find_idempotent_record(resource_type, key_hash, model):
+    if not key_hash:
+        return None
+    from app import db
+    from app.models import IdempotencyRecord
+    record = IdempotencyRecord.query.filter_by(
+        resource_type=resource_type, key_hash=key_hash
+    ).first()
+    return db.session.get(model, record.resource_id) if record else None
+
+
+def remember_idempotent_record(resource_type, key_hash, record):
+    if not key_hash:
+        return
+    from app import db
+    from app.models import IdempotencyRecord
+    db.session.flush()
+    db.session.add(IdempotencyRecord(
+        resource_type=resource_type,
+        key_hash=key_hash,
+        resource_id=record.id,
+    ))
+
+
+def verify_owner_token(record, token):
+    if not token or not record.owner_token_hash:
+        return False
+    candidate_hash = hashlib.sha256(token.encode('utf-8')).hexdigest()
+    return hmac.compare_digest(record.owner_token_hash, candidate_hash)
+
+
+def required_text(data, key, maximum, minimum=1):
+    value = data.get(key)
+    if not isinstance(value, str):
+        raise ValueError(f'{key} must be text.')
+    value = value.strip()
+    if len(value) < minimum or len(value) > maximum:
+        raise ValueError(f'{key} must be between {minimum} and {maximum} characters.')
+    return value
+
+
+def optional_text(data, key, maximum):
+    value = data.get(key, '')
+    if value is None:
+        return ''
+    if not isinstance(value, str):
+        raise ValueError(f'{key} must be text.')
+    value = value.strip()
+    if len(value) > maximum:
+        raise ValueError(f'{key} must not exceed {maximum} characters.')
+    return value

+def _validate_signature(extension, content):
+    signatures = {
+        'jpg': content.startswith(b'\xff\xd8\xff'),
+        'jpeg': content.startswith(b'\xff\xd8\xff'),
+        'png': content.startswith(b'\x89PNG\r\n\x1a\n'),
+        'webp': len(content) >= 12 and content.startswith(b'RIFF') and content[8:12] == b'WEBP',
+        'gif': content.startswith((b'GIF87a', b'GIF89a')),
+        'pdf': content.startswith(b'%PDF-'),
+        'docx': content.startswith(b'PK\x03\x04'),
+        'doc': content.startswith(b'\xd0\xcf\x11\xe0\xa1\xb1\x1a\xe1'),
+    }
+    return signatures.get(extension, False)
+

+def upload_asset(file, category, max_bytes, allowed_extensions):
+    if category not in BUCKETS:
+        raise StorageValidationError('Unsupported upload category.')
+    if not file or not file.filename:
+        return None
+
+    safe_name = secure_filename(file.filename)
+    if '.' not in safe_name:
+        raise StorageValidationError('The uploaded file must have a supported extension.')
+    extension = safe_name.rsplit('.', 1)[1].lower()
+    if extension not in allowed_extensions or extension not in MIME_TYPES:
+        raise StorageValidationError('This file type is not allowed.')
+
+    content = file.stream.read(max_bytes + 1)
+    if len(content) > max_bytes:
+        raise StorageValidationError('The uploaded file exceeds the size limit.')
+    if not _validate_signature(extension, content):
+        raise StorageValidationError('The file contents do not match its extension.')
+
+    bucket, _is_public = BUCKETS[category]
+    object_name = f'{secrets.token_hex(16)}.{extension}'
+    if current_app.config['STORAGE_BACKEND'] == 'supabase':
+        return _upload_supabase(bucket, object_name, content, MIME_TYPES[extension])
+    if current_app.config['STORAGE_BACKEND'] != 'local':
+        raise StorageError('STORAGE_BACKEND must be either local or supabase.')
+
+    os.makedirs(current_app.config['UPLOAD_FOLDER'], exist_ok=True)
+    local_path = os.path.join(current_app.config['UPLOAD_FOLDER'], object_name)
+    try:
+        with open(local_path, 'xb') as destination:
+            destination.write(content)
+    except OSError as exception:
+        raise StorageError('Could not save the uploaded file.') from exception
+    return object_name

+def delete_asset(reference):
+    if not reference:
+        return
+    if reference.startswith('sb://'):
+        parsed = urllib.parse.urlsplit(reference)
+        bucket = parsed.netloc
+        object_name = parsed.path.lstrip('/')
+        if bucket not in {details[0] for details in BUCKETS.values()}:
+            raise StorageError('Unknown storage bucket.')
+        encoded_name = urllib.parse.quote(object_name, safe='/')
+        _request('DELETE', f'object/{urllib.parse.quote(bucket, safe="")}/{encoded_name}')
+        return
+    local_path = os.path.join(current_app.config['UPLOAD_FOLDER'], reference)
+    if os.path.isfile(local_path):
+        os.remove(local_path)

+def asset_url(reference):
+    if not reference:
+        return None
+    if reference.startswith(('https://', 'http://')):
+        return reference
+    return '/api/uploads/' + urllib.parse.quote(reference, safe='')

+def resolve_asset(reference):
+    if reference.startswith('sb://'):
+        parsed = urllib.parse.urlsplit(reference)
+        bucket = parsed.netloc
+        object_name = parsed.path.lstrip('/')
+        if bucket not in {details[0] for details in BUCKETS.values()}:
+            raise StorageError('Unknown storage bucket.')
+        bucket_is_public = next(public for name, public in BUCKETS.values() if name == bucket)
+        if bucket_is_public:
+            return _public_url(bucket, object_name)
+        return _signed_url(bucket, object_name)
+    return None

+def _supabase_config():
+    base_url = current_app.config['SUPABASE_URL']
+    service_key = current_app.config['SUPABASE_SERVICE_ROLE_KEY']
+    if not base_url or not service_key:

+    return base_url, service_key
+
+
+def _request(method, endpoint, body=None, content_type=None):
+    base_url, service_key = _supabase_config()
+    headers = {
+        'apikey': service_key,
+        'Authorization': f'Bearer {service_key}',
+    }
+    if content_type:
+        headers['Content-Type'] = content_type
+    if body is not None and content_type == 'application/json':
+        body = json.dumps(body).encode('utf-8')
+    request = urllib.request.Request(
+        f'{base_url}/storage/v1/{endpoint}',
+        data=body,
+        headers=headers,
+        method=method,
+    )
+    try:
+        with urllib.request.urlopen(request, timeout=20) as response:
+            response_body = response.read()
+            return json.loads(response_body) if response_body else {}
+    except (urllib.error.URLError, TimeoutError, ValueError) as exception:
+        raise StorageError('Supabase Storage request failed.') from exception
+

+        f'object/{encoded_bucket}/{encoded_name}',
+        body=content,
+        content_type=content_type,
+    )

+    return urllib.parse.urljoin(f'{base_url}/storage/v1/', signed_path.lstrip('/'))

+## Idempotent create requests and owner tokens
+
+The browser sends an `Idempotency-Key` for community posts, marketplace and
+lost-and-found listings, events, opportunities, and institution posts. API
+clients may do the same. Keys must contain 16 to 200 characters. Reuse the same
+key only when retrying the same logical submission. The server stores only a
+hash of the key and returns the original resource and owner token for retries;
+a first successful create returns HTTP `201`, and a replay returns HTTP `200`.
+The key is optional for backward-compatible clients.
+
+The create response includes an opaque `owner_token`. Supply it in the JSON
+body for that resource's edit/delete endpoints. Keep it private; the browser
+stores it in local storage so the original poster can manage the content.
+Token-based ownership does not use or trust the displayed poster name.
+
+Example request:
+
+```http
+POST /api/posts
+Content-Type: application/json
+Idempotency-Key: 8bc09d44-046f-41d9-a3dd-2d225c25009d
+```

+
+## Status and prerequisites
+
+The repository includes a Render web-service manifest and Supabase-ready
+database/storage support. This does not mean that Supabase has been configured
+or that the current deployment has been migrated. No live database, storage
+project, DNS zone, or production deployment should be changed until the owner

+Before deploying, create the Supabase project and Render service, confirm

+## Supabase configuration
+
+1. Create a Supabase project and keep its database password private.
+2. Obtain the PostgreSQL connection URL from Supabase. Use the supported
+   connection type for the chosen Render region and connection limits.
+3. Configure the Supabase project URL and server-only service-role key.
+4. In Render, set the environment values listed below.
+5. Apply the app schema with `python -m flask --app run db upgrade` using the
+   production environment, via a controlled one-off job or deploy shell.
+6. Run `seed.py` only if the institution and advertising placement starter
+   records are needed.
+7. After the schema exists, review and apply
+   `supabase/migrations/202611230001_rls_and_storage.sql` in the Supabase SQL
+   editor. Confirm all policies and buckets in the Supabase dashboard.

+Do not run a migration against a live database until its target URL has been
+confirmed and a backup has been tested. The baseline migration refuses
+destructive downgrade; recovery should use a verified backup/restore procedure.

+Ensure all required columns exist in the SQLite database without breaking
+existing data. Only adds columns that are missing.

+from app import create_app, db
+from sqlalchemy import inspect, text
+
+app = create_app()
+with app.app_context():
+    insp = inspect(db.engine)
+
+    def add_col_if_missing(table, col, col_def):
+        cols = [c['name'] for c in insp.get_columns(table)]
+        if col not in cols:
+            with db.engine.connect() as conn:
+                conn.execute(text(f'ALTER TABLE {table} ADD COLUMN {col} {col_def}'))
+                conn.commit()
+            print(f'  Added {table}.{col}')
+        else:
+            print(f'  OK {table}.{col}')
+
+    print('Checking post table...')
+    add_col_if_missing('post', 'updated_at', 'DATETIME')
+    add_col_if_missing('post', 'owner_token_hash', 'VARCHAR(64)')
+    add_col_if_missing('post', 'file_path', 'VARCHAR(300)')
+    add_col_if_missing('post', 'file_type', 'VARCHAR(20)')

+    print('Checking marketplace_item table...')
+    add_col_if_missing('marketplace_item', 'owner_token_hash', 'VARCHAR(64)')
+
+    print('Checking lost_found_item table...')
+    add_col_if_missing('lost_found_item', 'owner_token_hash', 'VARCHAR(64)')

+    try:

+def run_migrations_offline():
+    """Run migrations in 'offline' mode.
+
+    This configures the context with just a URL
+    and not an Engine, though an Engine is acceptable
+    here as well.  By skipping the Engine creation
+    we don't even need a DBAPI to be available.
+
+    Calls to context.execute() here emit the given string to the
+    script output.
+
+    """
+    url = config.get_main_option("sqlalchemy.url")
+    context.configure(
+        url=url, target_metadata=get_metadata(), literal_binds=True
+    )
+
+    with context.begin_transaction():
+        context.run_migrations()
+
+
+def run_migrations_online():
+    """Run migrations in 'online' mode.
+
+    In this scenario we need to create an Engine
+    and associate a connection with the context.
+
+    """
+
+    # this callback is used to prevent an auto-migration from being generated
+    # when there are no changes to the schema
+    # reference: http://alembic.zzzcomputing.com/en/latest/cookbook.html
+    def process_revision_directives(context, revision, directives):
+        if getattr(config.cmd_opts, 'autogenerate', False):
+            script = directives[0]
+            if script.upgrade_ops.is_empty():
+                directives[:] = []
+                logger.info('No changes in schema detected.')
+
+    conf_args = current_app.extensions['migrate'].configure_args
+    if conf_args.get("process_revision_directives") is None:
+        conf_args["process_revision_directives"] = process_revision_directives
+
+    connectable = get_engine()
+
+    with connectable.connect() as connection:
+        context.configure(
+            connection=connection,
+            target_metadata=get_metadata(),
+            **conf_args
+        )
+
+        with context.begin_transaction():
+            context.run_migrations()
+
+
+if context.is_offline_mode():
+    run_migrations_offline()
+else:
+    run_migrations_online()

+def _add_column_if_missing(table_name, column):
+    existing = {item['name'] for item in inspect(op.get_bind()).get_columns(table_name)}
+    if column.name not in existing:
+        if op.get_bind().dialect.name == 'sqlite':
+            with op.batch_alter_table(table_name) as batch:
+                batch.add_column(column)
+        else:
