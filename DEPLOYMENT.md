# CampusConnect web deployment

The web app is deployed on Render from this repository. Preserve the existing
database, upload directory, and `seed.py` build step when changing the service
configuration.

## Required Render environment variables

- `SECRET_KEY`: generated by Render and used for application signing.
- `ADMIN_USERNAME`: the administrator login name.
- `ADMIN_PASSWORD_HASH`: a Werkzeug password hash, never the clear-text password.
- `AI_API_KEY`: optional secret for the Study Assistant's OpenAI-compatible provider.
- `AI_API_BASE_URL`: optional HTTPS provider URL (defaults to `https://api.openai.com/v1`).
- `AI_MODEL`: optional provider model name (defaults to `gpt-4o-mini`).

Generate a password hash locally without putting the password in shell history:

```text
python -c "from getpass import getpass; from werkzeug.security import generate_password_hash; print(generate_password_hash(getpass()))"
```

Set the returned hash as `ADMIN_PASSWORD_HASH` in the Render service's
environment settings. Do not commit the password or its hash to Git.

The Study Assistant returns a clear not-configured response until `AI_API_KEY`
is set in Render. Set the provider key in the Render dashboard, not in source
control or chat. Provider API usage may incur charges. Users are told that
study questions are sent to the configured AI provider. Configure a trusted
HTTPS-compatible API endpoint only.

The **More** navigation section contains Jobs & Attachments, Accommodation,
Notes & Resources, Campus Deals, Events Calendar, Student Polls, Anonymous
Confessions, Lost Documents, Buy & Sell Services, and the AI Study Assistant.
These listings use new additive database tables created by the existing
`seed.py` build step; existing content tables are not replaced. Anonymous
confessions do not store a poster identity, and lost-document listings do not
publish contact fields. Admin feature moderation is available through the
authenticated `/api/admin/features` endpoints.

The administrator login now requires those environment variables. New admin
sessions use a new token version; older sessions are rejected after deploying
this update. Because a previous version of the repository included a
hard-coded admin password, replace it with a new password before deployment.
Do not reuse the previous password.

## Deploy

1. Set the Render environment variables above before deploying.
2. Push the reviewed website changes to the branch connected to the Render
   service, or use Render's **Manual Deploy** action for that commit.
3. Wait for the build and service health check to succeed.
4. Verify the home page, feed, search, sign-in, and `/admin` login.

The build command currently installs `requirements.txt` and runs `seed.py`.
Review any future database schema changes and backups before changing that
command or the service's storage configuration.
